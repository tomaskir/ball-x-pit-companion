# Icon credits

Base-game icons in this directory were downloaded from
[ballxpit.wiki.gg](https://ballxpit.wiki.gg) via the wiki's MediaWiki API
(`api.php?action=query&prop=imageinfo`) on 2026-09-13.

The *Risen Ballbylon* icons and character art were extracted from the
**BALL x PIT v1.308, Risen Ballbylon** game assets (Unity 6000.0.62f1,
IL2CPP) on 2026-11-13; the wiki has no DLC icons. The extracted source tree is
not committed.

The site favicon (`public/favicon.ico`, 32×32) is the wiki's site favicon —
the game's ball icon — downloaded from the same source on 2026-10-10; same
rights holder and disclaimer as above.
Filenames are kebab-case versions of the entity names (e.g.
`vampire-lord.png`, `archers-effigy.png`, `the-itchy-finger.png`). All files
verified as valid PNGs (magic bytes, non-zero size).
